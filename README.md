# Reading Tracker

Первая версия личного книжного трекера.

## Как запустить локально

Не открывайте `index.html` двойным щелчком: браузер может запретить `fetch()` локального `books.xlsx`.

В VS Code установите расширение **Live Server** → правой кнопкой по `index.html` → **Open with Live Server**.

## Как обновлять книги

1. Измените `books.xlsx`.
2. Замените файл `books.xlsx` в корне репозитория.
3. GitHub Pages после обновления репозитория покажет новые данные.

## Обложки

Сайт сначала использует ссылку из столбца **«Обложка»** в `books.xlsx`.

Если ячейка пустая или ссылка не загрузилась, сайт пытается найти обложку через Google Books API по названию + автору и кэширует найденный результат в браузере.
